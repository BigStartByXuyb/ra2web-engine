# 分阶段计划

每阶段都有可验证的退出条件；未满足退出条件不得进入下一阶段。

## P0 逆向与数据层（进行中）

- 逆向流程可用：REA + Ghidra 能对 `GAME.EXE` 出总览、检索函数/字符串、反编译单函数。
- 函数清单分类完成：按子系统（INI/MIX/美术/渲染/网络/音频/存档）落到 `docs/ENGINE-MAP.md`。
- `packages/formats` 能读 MIX / INI / CSF；`packages/rules` 能把 `rules.ini` 解析成领域模型。

**退出条件**：命令行能打印出"某单位的全部数值"，且数值与原版游戏内一致（逐项核对）。

## P1 模拟内核最小闭环

- 一张地图、双方各一辆车、移动指令、时间推进；
- 确定性：同一输入序列在 Node 与浏览器里产生逐 tick 相同的状态哈希。

**退出条件**：把两段录制输入重放，状态哈希一致；有回归快照测试。

## P2 渲染与首个可玩切片

- 地形（TMP/地图）、载具（VXL）、步兵（SHP）显示；摄像机与缩放；
- 选中、移动、生产队列的界面。

**退出条件**：能在一张官方地图上开一局、造出单位并移动，画面与原版布局一致。

## P3 战斗与经济

- 武器/弹头/护甲结算、建造树、矿车与矿、电力、维修。

**退出条件**：与原版对照表逐项验证伤害公式（用原版函数地址作为依据）。

## P4 完整对局

- AI、迷雾、地图触发器、胜负条件、存档。

**退出条件**：完整打完一局遭遇战，结果与原版一致。

## P5 联机与 MOD 生态

- 锁步联机、重放、校验；MOD 加载（含数据型 MOD）。

**退出条件**：两人跨机对战不崩；能加载共和国之辉并开局。

## 规模说明

原版 `GAME.EXE` 有 8442 个函数，本项目只复刻**行为**，不逐函数翻译。工作量集中在：
数据格式、模拟规则、渲染管线、联机协议四块骨架；骨架完成后，其余多为重复模式。
