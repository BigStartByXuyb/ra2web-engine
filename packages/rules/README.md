# @ra2web/rules

把原版 `rules.ini` / `art.ini` 这类 INI 数据变成强类型领域模型。

## 职责

- 还原原版的**加载顺序与覆盖语义**：同一批文件按顺序加载，后加载的同名键覆盖先加载的，
  节内键互不影响（逐键覆盖，不是整节替换）。
- 保留**无损原文**（`RawRules`），供核对与调试；在此之上再提供强类型视图。
- 解析失败不抛异常，以 `ParseIssue` 列表随结果返回，便于逐项核对。

## 不负责

- 不做模拟、不读地图、不碰渲染。
- 不提供"猜测式"默认值：原版没写的键就是 `undefined`。

## 依据

加载顺序来自原版 `GAME.EXE` 的规则集加载例程 `FUN_005129c0`（见 `docs/ENGINE-MAP.md`）：
先 `RULE*.INI`，再 `RULES.INI`，随后 `ART.INI`、`LANGRULE.INI`、`AI.INI`。
