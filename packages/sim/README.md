# @ra2web/sim

确定性模拟内核。给定相同的初始状态与相同的指令序列，**逐 tick 的状态必须完全一致** ——
这是联机、重放与回归测试的共同地基。

## 确定性约束（硬性）

- 不使用浮点做位置与速度运算：一律**定点整数**（1 格 = 256 单位）。
- 不使用 `Date.now()` / `performance.now()` / `Math.random()`：时间来自 tick 计数，随机来自种子 RNG。
- 不接触 DOM、WebGL、计时器、网络；不依赖 Node 专有 API。
- 遍历顺序必须稳定：单位按 id、路径按索引、指令按入队顺序。

## 不负责

- 不做渲染、输入、网络传输；只维护状态与状态转移。
